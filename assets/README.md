# assets/

Input files for `@capacitor/assets`. These are auto-generated by `npm run gen:icons`
and consumed by `npx @capacitor/assets generate --android` to stamp the Android
mipmap launcher icon files.

Do not edit these files manually — edit `resources/icon.svg` and re-run `npm run gen:icons`.

| File | Purpose | Preview |
|---|---|---|
| `icon-only.png` | Full icon with background. Used for legacy launcher icons (Android < 8). | <img src="icon-only.png" width="64"> |
| `icon-foreground.png` | Foreground layer for adaptive icons (Android 8+). | <img src="icon-foreground.png" width="64"> |
| `icon-background.png` | Background layer for adaptive icons — solid `#13121c`. | <img src="icon-background.png" width="64"> |
