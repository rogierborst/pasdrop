# assets/

Input files for `@capacitor/assets`. These are auto-generated by `npm run icons:render`
and consumed by `npx @capacitor/assets generate --android` to stamp the Android
mipmap launcher icon files.

Do not edit these files manually — edit `resources/icon.svg` and re-run `npm run icons:sync`.

| File | Purpose |
|---|---|
| `icon-only.png` | Full icon with background. Used for legacy launcher icons (Android < 8). |
| `icon-foreground.png` | Foreground layer for adaptive icons (Android 8+). |
| `icon-background.png` | Background layer for adaptive icons — solid `#13121c`. |
